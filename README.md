# LINE 勤怠連絡システム (LHD_Line_Holiday) - セットアップガイド

本システムは、**遅刻・早退・休み（欠勤・有給）の連絡** に特化したLINE連携ツールです。  
クレジットカード不要・サーバー代完全無料で構築・運用できます。

---

## 🌟 主な特徴

- **15秒で簡単連絡**: 遅刻・早退・欠勤・有給をスマホからワンタップで連絡。
- **15分刻みの時刻指定**: 遅刻・早退時の出勤/退勤予定時刻は15分単位でスムーズに選択。
- **「その他」理由の必須制御**: 「その他」を選択した時のみ詳細理由が必須入力になり、連絡漏れを防止。
- **現場ごとの所定労働日数に対応**: 現場マスタで現場ごとの月間所定日数を設定可能。
- **出勤率 & グラフ自動集計ダッシュボード**:
  - 管理者専用シートに **従業員ごとの出勤率・遅刻回数・早退回数・欠勤日数・有給日数** を自動集計。
  - 出勤率バーグラフ ＆ 連絡種別内訳円グラフがリアルタイムに自動更新。
- **管理者への即時プッシュ通知**: 申請が入ると即座に管理者のLINEへ詳細が届きます。

---

## 🛠 必要なもの

1. Googleアカウント（Googleスプレッドシート用）
2. LINE Developersアカウント（Messaging API & LINEログイン）
3. GitHubアカウント（LIFF画面の無料公開用）

---

## STEP 1: Googleスプレッドシート ＆ GASの作成

1. **[Googleスプレッドシート](https://spreadsheet.new/)** を新規作成します。
2. シート名を「`勤怠連絡管理（LHD）`」などに変更します。
3. メニューバーの **「拡張機能」 ＞ 「Apps Script」** をクリックします。
4. エディタに最初から書かれている `myFunction()` を消去します。
5. プロジェクト内の `gas/code.js` の内容をすべてコピーして貼り付けます。
6. コード上部にある設定項目をご自身の値に設定します：
   - `CHANNEL_ACCESS_TOKEN`: LINE公式アカウントのアクセストークン（長期）
   - `LIFF_ID`: LINE Developersで発行するLIFF ID
   - `ADMIN_LINE_USER_IDS`: 通知を受け取りたい管理者のLINEユーザーID（※後から追加可能）
7. ツールバーの **「保存（フロッピーアイコン）」** をクリックします。

### 初回初期化の実行：
1. Apps Script画面上部の実行関数プルダウンから **`initSpreadsheet`** を選択し、**「実行」** をクリックします。
2. 承認画面が出たら、「権限を確認」＞ ご自身のアカウント選択 ＞ 「詳細」＞ 「無題のプロジェクト（安全ではないページ）に移動」＞ 「許可」をクリックします。
3. 実行完了後、スプレッドシートに戻ると以下の4つのシートが自動生成されます：
   - **`連絡履歴`**: 受信した連絡がリアルタイムに蓄積
   - **`ユーザー管理`**: LINEから登録した従業員情報
   - **`現場マスタ`**: 現場名と今月の所定労働日数（必要に応じて自由に追加・変更可能）
   - **`集計ダッシュボード`**: 従業員別の出勤率テーブル ＆ 自動描画グラフ

---

## STEP 2: GASを「ウェブアプリ」としてデプロイ

1. Apps Script画面の右上にある **「デプロイ」 ＞ 「新しいデプロイ」** をクリックします。
2. 種類の選択（歯車アイコン）から **「ウェブアプリ」** を選択します。
3. 設定項目を入力します：
   - **説明**: `LHD API v1`
   - **次のユーザーとして実行**: `自分`
   - **アクセスできるユーザー**: ⚠️ **`全員 (Anyone)`** に変更してください。
4. **「デプロイ」** をクリックします。
5. デプロイ完了後、表示された **「ウェブアプリの URL」**（`https://script.google.com/macros/s/XXXXX/exec`）をコピーして手元にメモします。

---

## STEP 3: LIFFフロントエンドの設定

1. `public/app.js` を開きます。
2. 5行目と6行目を、ご自身の値に書き換えます：
   ```javascript
   const GAS_API_URL = 'https://script.google.com/macros/s/XXXXX/exec'; // STEP 2のURL
   const LIFF_ID = 'YOUR_LIFF_ID'; // LINE DevelopersのLIFF ID
   ```
3. 保存します。

---

## STEP 4: GitHub Pagesで画面を無料公開

1. GitHubで新規リポジトリを作成し、`LHD_Line_Holiday` のファイル一式をアップロード（またはpush）します。
2. リポジトリの **「Settings」 ＞ 「Pages」** を開きます。
3. **Build and deployment** 設定：
   - **Source**: `Deploy from a branch`
   - **Branch**: `main` ＞ フォルダは **`/public`**（または `/` のルート直下に置く場合は root）を選択し、「Save」をクリックします。
4. 数分待つと、公開URL（例: `https://<ユーザー名>.github.io/<リポジトリ名>/`）が発行されます。これがLIFFエンドポイントURLになります。

---

## STEP 5: LINE Developers の設定

### 1. Webhook URL の設定
1. **LINE Developers** ＞ 対象のMessaging APIチャネル ＞ **「Messaging API設定」** タブを開きます。
2. **Webhook URL** に、STEP 2で取得した **「GASのウェブアプリURL」** を貼り付けます。
3. 「Webhookの利用」を **ON** にします。

### 2. LIFF アプリの作成
1. LINE Developers ＞ 対象のチャネル（またはLINEログインチャネル） ＞ **「LIFF」** タブを開きます。
2. **「追加」** をクリックし、以下のように設定します：
   - **LIFFアプリ名**: `勤怠連絡`
   - **サイズ**: `Full` または `Tall`
   - **エンドポイントURL**: STEP 4で発行されたGitHub PagesのURL（末尾に `/` を推奨）
   - **Scope**: `profile`, `openid` にチェック
3. 作成後に表示される **LIFF ID** をコピーし、STEP 1の `gas/code.js` および STEP 3の `public/app.js` に貼り付けてください。

---

## 💡 管理者向けTips: 自分のLINE IDを取得して通知を受け取る方法

1. 作成したLINE公式アカウントを友だち追加します。
2. トーク画面で **「マイID」** とメッセージを送信します。
3. BotがあなたのLINEユーザーID（`Uxxxxxxxx...`）を返信します。
4. そのIDを `gas/code.js` の `ADMIN_LINE_USER_IDS` 配列に追加し、GASを「デプロイの管理」から新バージョンとしてデプロイすると、連絡が届いた際に即時プッシュ通知を受け取れるようになります。

## 📊 出勤率 ＆ グラフの活用方法

- **出勤率の計算式**:
  $$\text{出勤率} = \frac{\text{所定労働日数} - \text{欠勤日数}}{\text{所定労働日数}} \times 100\%$$
- **有給休暇**: 出勤扱いとして集計（欠勤には含めず、有給取得日数としてカウント）
- **遅刻・早退**: 出勤率は減算せず、それぞれ「○回」としてカウント
- **現場ごとの所定日数変更**: 「現場マスタ」シートの「所定労働日数」の数値を変更すると、ダッシュボードの計算も即座に再計算されます。
